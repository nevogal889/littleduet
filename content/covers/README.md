# Song covers

Every song uses its lesson-style cover: the song's character, title and a keyboard strip with the first notes lit,
rendered by `video/render.py` (copied here from `video/out/<songId>/cover.jpg`). The app reads `content/covers/<songId>.jpg`
first, so replacing a file here changes that song's cover.

`content/covers-watercolor/` keeps 10 storybook watercolour covers made with Figma AI, in case the style is revisited.
The earlier Pixabay photo set is no longer used.
